미드저니(Midjourney)나 스테이블 디퓨전(Stable Diffusion) 같은 이미지 생성 AI는 백지 위에 붓으로 그림을 그리지 않습니다. 대신 **무작위로 지지직거리는 노이즈(잡음) 화면에서 출발해, 한 꺼풀씩 잡음을 걷어내며 그림을 조각**해 냅니다. 이 방식을 **확산 모델(Diffusion Model)**이라고 합니다.

## 노이즈에서 시작해 매번 다르게 나온다

위 위젯은 실제 손글씨 데이터로 학습시킨 초소형 확산 모델입니다.

- **시작 노이즈(Seed)**: `0 / 16` 단계의 화면은 무작위 난수로 만든 순수 잡음입니다. `🎲 새 노이즈`를 누르면 시작 화면(Seed) 자체가 바뀝니다.
- **단계별 잡음 제거**: `1단계`나 `자동`을 누르면 신경망이 현재 화면을 보고 "어느 방향이 우리가 원하는 숫자에 더 가까운가"를 계산해 16단계에 걸쳐 노이즈를 걷어냅니다.
- **같은 숫자, 다른 모양**: 같은 숫자(`3` 등)를 선택해도 시작 노이즈(`Seed`)가 다르면, 처음 노이즈에 우연히 뭉쳐 있던 점들의 위치가 달라서 매번 다른 필체와 기울기의 그림이 만들어집니다.

## 안내 강도 (Guidance)의 역할

하단의 **안내 강도** 슬라이더는 언어 모델의 창의성(Temperature)과 반대 역할을 합니다.

- 값을 낮추면(`1.0`) 시작 노이즈의 우연한 형태를 더 자유롭게 따르지만 숫자가 흐릿하거나 엉뚱한 모양이 나올 수 있습니다.
- 값을 높이면(`3.5~4.0`) 선택한 숫자 조건을 강하게 밀어붙여 선명하고 또렷한 숫자가 만들어집니다.

결국 글자 생성 AI(`02_next-token`)가 앞 문맥을 보고 다음 단어를 고르듯, 이미지 생성 AI는 **현재 노이즈 화면과 조건(프롬프트)을 보고 "조금 덜 노이즈 낀 다음 화면"**을 반복해서 예측해 그림을 완성합니다.
